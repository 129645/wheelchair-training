# 電動輪椅操作練習

用滑鼠操作影片裡的電動輪椅,沿著地上的路徑前進並閃過行人的練習遊戲。
影片是實際跟拍電動輪椅行進的畫面,路徑與行人由程式畫在地面上。

- 首頁:`index.html`
- 遊戲:`games/wheelchair-drive.html`
- 遊戲影片:`games/wheelchair-drive-video.mp4`(要和遊戲網頁放在同一個資料夾,檔名不能改)

上線後的網址:`https://<帳號>.github.io/<repo 名稱>/games/wheelchair-drive.html`

## 操作

| 動作 | 結果 |
|---|---|
| 按住滑鼠左鍵 | 輪椅前進 |
| 放開左鍵 | 輪椅停下 |
| 滑鼠左右移動 | 像搖桿:離畫面中央越遠,轉得越快;回到中央就直走 |

備用操作:鍵盤方向鍵上(或空白鍵)前進、左右鍵轉向;平板用手指按住畫面前進、左右滑動轉向。
建議用電腦搭配滑鼠,以 Chrome 或 Edge 開啟。

## 關卡

每關是影片循環 3 次,約 1 分鐘、52 公尺。

| 關卡 | 內容 |
|---|---|
| 第一關 | 沿著彎曲的路徑前進 |
| 第二關 | 路徑上有 4 位行人,一次一位,閃過後回到路徑 |
| 第三關 | 3 組行人,每組兩位、一左一右,要連續左右閃避 |

選單可調整:
- 路徑寬度:窄(輪椅寬度的 1.3 倍,預設)、中(1.6 倍)、寬(2 倍)
- 轉向靈敏度:低、中(預設)、高

## 結果

每關結束顯示:完成時間、保持在路徑內的比例、壓到邊線的次數、平均偏離路徑中央的距離;
第二、三關另外顯示順利閃過與碰到行人的次數(繞過行人的路段不列入路徑計算)。

遊戲不儲存成績,也不會上傳任何資料。這些數字是當次練習的紀錄,不是評估或診斷結果。
實際給個案使用前,建議先由治療師試玩並調整路徑寬度與靈敏度。

## 調整內容

用文字編輯器開啟 `games/wheelchair-drive.html`,搜尋 `const LEVELS`:
- `curve`:路徑的彎曲程度
- `peds`:每位行人的位置,格式是 `[距離起點幾公尺, 偏離路徑中央幾公尺]`
